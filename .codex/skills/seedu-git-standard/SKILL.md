# SE-EDU Git standard

Use this skill whenever creating, amending, or proposing a commit, and when
creating or naming a branch. The authoritative rules are documented at:
https://se-education.org/guides/conventions/git.html

Before committing, check that:

- The subject is meaningful, imperative, capitalized, has no final period, and is at most 72 characters (prefer 50 or fewer). An optional scope or category prefix is allowed.
- A non-trivial commit has a blank line followed by a body wrapped at 72 characters. The body explains what changed and why, not how; use present tense for the situation and imperative mood for the change.
- The branch name is meaningful, uses kebab case, and includes the issue number followed by relevant keywords when the work relates to an issue.

Keep commits focused enough that the message can explain the change clearly.
Do not create or push a commit unless the user explicitly asks for it.
